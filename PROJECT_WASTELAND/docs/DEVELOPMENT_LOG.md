## 발견·수정한 문제

1. 테스트 봇이 짧은 프레임 묶음에서 고정 업데이트 0회 → 입력 누락. 루프에 결정론 모드를 추가하고, 입력 `pressed` 를 업데이트가 소비할 때까지 래치하도록 변경 (프레임레이트에 따른 입력 누락/중복 방지 — 실제 게임에도 해당하는 버그).
2. 총알이 조준점과 평행하게 어긋남: 조준각을 가슴 높이 기준점에서 계산했는데 탄은 발 위치에서 발사됨. 커서를 가슴 높이 평면으로 해석하고 캐릭터 위치에서 조준하도록 수정.
3. 상호작용 대상이 커서와 다른 물체로 잡힘 → 커서 아래 물체 우선 선택.
4. 타일 텍스처 대비가 과해 표범무늬처럼 보이고 암반이 과다 → 텍스처·암반 빈도 조정, 굴착 구멍 대비 강화.
5. (실기 패드 테스트) 시작 직후 패드가 죽음: 시작 시 연 패드에 대해 SDL 이 `JOYDEVICEADDED` 를 다시 보내고,
   중복 객체를 `quit()` 하면 같은 장치를 공유하는 원래 핸들까지 닫혔다. 이미 열린 장치는 닫지 않고 무시하도록 수정 + 회귀 테스트.
6. Xbox 360 패드에서 VIEW/MENU 표기가 실제 버튼(BACK/START)과 달라 혼동 → 패드 이름에 따라 표기 변경.
7. 자동 플레이 테스트가 시드에 따라 실패: 실제 패드 입력 유입(`WASTELAND_NO_PAD` 로 차단), 굴착 중 카메라 이동으로
   커서가 옆 칸을 가리킴(매 프레임 재조준), 사격 클릭 위치 오류, 벽에 둘러싸인 위치에서 사격 → 봇 수정. 8개 시드 17/17 통과.
