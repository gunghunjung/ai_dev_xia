# PROJECT WASTELAND

2D 쿼터뷰 포스트아포칼립스 서바이벌 액션 RPG — Python 3.11+ / pygame-ce / SQLite.

아무것도 없는 황무지에서 시작해 돌과 나뭇가지로 첫 도구를 만들고, 땅을 파 과거 문명의 흔적을 발굴하고,
희소한 탄약과 물로 살아남는 게임입니다. NPC·퀘스트 없이 모든 진행이 가능합니다.

## 실행

```bash
python -m venv .venv
```
```bash
.venv\Scripts\pip install -r requirements.txt
```
```bash
.venv\Scripts\python main.py
```

배포용 실행 파일: `.venv\Scripts\pyinstaller build.spec --noconfirm` → `dist\ProjectWasteland\ProjectWasteland.exe`
(세이브는 exe 옆 `saves\` 폴더에 저장됩니다.)

## 조작

| 동작 | 키보드 / 마우스 | Xbox 패드 |
|---|---|---|
| 이동 | WASD | 왼쪽 스틱 (기울기 = 속도) |
| 조준 | 마우스 (360°) | 오른쪽 스틱 (마지막 방향 유지, 선택적 조준 보정) |
| 공격 / 사격 | 좌클릭 (근접은 누르고 있으면 연속) | RT |
| 조준(정밀) / 설치 취소 | 우클릭 | LT |
| 근접 공격 (총기 개머리) | V | RB |
| 재장전 | R | X (총 장착 시) |
| 발굴 (누르고 있기) | F | X (도구 장착 시) |
| 상호작용 (줍기·채집·수색·물) | E | A |
| 회피 구르기 | Space | LB / B |
| 달리기 | Shift | L3 (토글) |
| 무기 전환 | Q | Y |
| 퀵슬롯 | 1–5 | 십자키 (↑→↓←) |
| 인벤토리 / 제작 | I·Tab / C | View (360 패드: BACK) |

| 빠른 저장 / 불러오기 | F5 / F9 | 일시 정지 메뉴 |

인벤토리: 드래그 앤 드롭, 우클릭/`X`/패드 `Y` = 메뉴(사용·장착·핫바 지정·나누기·버리기·옮기기),
`Z`/패드 `X` = 나누기, Shift+클릭 = 상자와 빠른 이동, 아이템 위에서 1–5 = 핫바 지정.
모든 버튼은 설정 → 버튼 매핑에서 변경할 수 있습니다.

## 생존 가이드 (첫 날)

1. 주변의 **돌무더기·나뭇가지·마른 덤불**을 `E`로 채집한다.
2. `C` → **간이 삽**(돌 2, 나뭇가지 2, 섬유 2) 또는 **돌도끼**를 만든다.
3. 땅을 `F`로 판다. 녹슨 얼룩이 있는 땅 아래에는 은닉물이 묻혀 있다. 소리가 적을 부른다.
4. 물웅덩이의 물은 오염돼 있다. 빈 병에 담아 **모닥불**에서 끓이자.
5. 도로를 따라가면 버려진 **경찰차**가 있다. 탄약은 거의 없다.
6. 밤은 춥고 위험하다. 모닥불 곁에서, 침낭을 깔고 버텨라.

## 구조

```
engine/     게임 루프(고정 60Hz), 카메라(아이소 투영), 입력(논리 액션), 에셋/오디오, 렌더러
entities/   플레이어, 적(AI 상태머신), 야생동물, 투사체(풀링), 월드 오브젝트
systems/    전투, 굴착, 생존, 인벤토리, 제작, 소음, 날씨, 시간, 스폰, 이펙트, 플레이어 컨트롤러
world/      청크, 지형 DB, 지층 매장물, 결정론적 월드 생성, 월드 매니저
ui/         HUD, 인벤토리, 제작, 상태, 설정, 메뉴, 패드/키보드 버튼 안내
database/   SQLite 세이브(버전·마이그레이션·원자적 쓰기·백업), 월드/플레이어 저장소
interfaces/ 서버 권한형 확장을 위한 서비스 인터페이스 (현재 Local 구현)
data/       아이템·무기·적·지형·레시피·전리품·입력 프로필·일지 (JSON)
assets/     PNG/WAV 를 넣으면 절차적 플레이스홀더를 자동 대체
tests/      pytest 단위 테스트 + 헤드리스 자동 플레이 테스트
```

에셋 교체: `assets/objects/dead_tree_0.png`, `assets/terrain/sand_0.png`, `assets/sounds/pistol.wav` 처럼
키 이름과 같은 파일을 두면 해당 플레이스홀더 대신 사용됩니다.

## 테스트

```bash
.venv\Scripts\python -m pytest -q tests
```
